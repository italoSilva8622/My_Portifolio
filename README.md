# 💻 Portfólio Pessoal — Italo Silva

Meu primeiro projeto de portfólio pessoal, desenvolvido durante meus estudos no **DevClub**, com o objetivo de colocar em prática meus conhecimentos em desenvolvimento web.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Google Fonts

## 📌 Sobre o projeto

O projeto apresenta uma página pessoal com:
- Apresentação e introdução pessoal.
- Seção de tecnologias e conhecimentos.
- Links para redes profissionais.
- Layout com identidade visual própria.

## 🎯 Objetivo

Praticar os fundamentos de HTML e CSS, desenvolver minha criatividade e aprimorar minhas habilidades em desenvolvimento Front-End.

## 📚 Status do projeto

Em desenvolvimento. Novas melhorias e funcionalidades serão adicionadas conforme minha evolução nos estudos.
